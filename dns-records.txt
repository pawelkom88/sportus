## 1. DNS-AID Entrypoint Records (HTTPS / SVCB ServiceMode)

DNS-AID uses ServiceMode SVCB or HTTPS records under the `_agents` subdomain namespace:

### Record 1: Agent Index (_index._agents)
- **Type**: `HTTPS` (or `SVCB`)
- **Name / Host**: `_index._agents.sportus.com.pl.`
- **TTL**: `3600`
- **Priority / Weight**: `1`
- **Port**: `443`
- **Target**: `sportus.com.pl.`
- **Parameters**: `alpn="h2,h3"`

BIND Zonefile syntax:
```dns
_index._agents.sportus.com.pl. 3600 IN HTTPS 1 sportus.com.pl. alpn="h2,h3" port=443
```

- **TTL**: `3600`

## 4. DNSSEC Note

The DNS-AID IETF specification (draft-01+) expects DNSSEC validation (`AD=true`).
- **Current DNS Provider**: Netlify DNS (`dns1.p08.nsone.net`).
- Netlify DNS does not currently support DNSSEC signing.
- If strict DNSSEC validation is required by the scanner/resolver, delegate the zone to a DNS provider that supports DNSSEC (e.g. Cloudflare DNS or Route 53) and add the DS record at the registrar.
