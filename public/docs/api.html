Sportuś API Documentation

Official public API documentation for Sportuś sports academy in Gdańsk.

API Catalog & OpenAPI

  • OpenAPI 3.0 Specification: /api/openapi.json
  • RFC 9727 API Catalog: /.well-known/api-catalog
  • Health Status: /api/health

Endpoints

GET /api/health

Returns service operational status.

GET /api/classes

Returns sports programs, target age groups, and descriptions.

GET /api/schedule

Returns weekly timetable of all sports classes across Gdańsk locations.
